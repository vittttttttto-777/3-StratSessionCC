# Стратсессия №3 · зоны ответственности

Одностраничный инструмент для стратегической сессии Coral Club: рассадка, заставка, анонс, расписание двух дней с таймером, карта зон ответственности (конфликты, коммуникации, серые зоны), портфолио функций. Интерфейс на русском и английском.

## Как открыть

- **Ноутбук ведущего:** `https://<ваш-логин>.github.io/<репозиторий>/`
- **Проектор:** та же ссылка с `#screen` в конце — экран сам переключает слайды и язык вслед за ведущим.

## Редактирование

1. Нажмите «Вход для редактора» в шапке и введите PIN.
2. На слайдах расписания и рассадки появятся кнопки «Редактировать». Сохранённые изменения сразу видны на всех открытых экранах.
3. Включите «Транслировать на проектор» — экран с `#screen` будет показывать тот же слайд и язык, что у вас.
4. «Выйти» убирает PIN из этого браузера.

PIN не хранится в репозитории. Без него страницу можно только смотреть.

## Данные

- Расписание, рассадка и текущий слайд хранятся в Supabase (таблица `strat3_state`). Запись — только через функцию `strat3_save` с проверкой PIN.
- Данные анкет (портфолио, матрицы) встроены в `index.html`. Чтобы обновить их, пересоберите страницу и замените файл.
