# Стратсессия №3 · День 3 · Полномочия Дивизионов 1.0

Одна страница `index.html` без сборки: презентация дня (11 слайдов) и общая матрица полномочий по 127 процессам «Красных линий». Всё переключается RU / EN кнопкой в верхней панели. Работает на GitHub Pages, данные хранятся в Supabase.

Вход — по паролю участника в окне на входе, как во второй день (пароль тот же). Содержимое страницы зашифровано: без пароля в `index.html` видно только окно входа. После входа браузер запоминает доступ.

## Что внутри

| Путь | Назначение |
|---|---|
| `index.html` | Окно входа и зашифрованное приложение: презентация, матрица, решения CEO, справочник функций, сводка, лестница |
| `vendor/` | ExcelJS (выгрузка в Excel) и supabase-js — локальные копии, чтобы не зависеть от CDN |
| `assets/` | Логотип дня 3 (`logo-mark.svg`), иконки и превью ссылки (`og-image.png`) |
| `supabase/migrations/` | SQL: таблица состояния сессии, справочные таблицы и представления, вход по паролю. Сами данные матрицы в репозиторий не выкладываются — они уже в базе |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Публикация на GitHub Pages

1. Создайте репозиторий, например `3-StratSession3day`.
2. Загрузите содержимое пакета в корень: **Add file → Upload files**, перетащите всё, включая `assets/`, `vendor/`, `supabase/` и `.nojekyll`.
3. **Settings → Pages → Build and deployment:** Source — *Deploy from a branch*, Branch — `main`, папка — `/ (root)`.
4. Через 1–2 минуты сайт откроется по адресу `https://vittttttttto-777.github.io/<имя-репозитория>/`.
5. Для превью в мессенджерах замените в `index.html` `og:image` на полный адрес: `https://vittttttttto-777.github.io/<имя-репозитория>/assets/og-image.png`.

Обновление — загрузить новый `index.html` поверх старого.

## Как хранятся данные (Supabase `awwhrlenhqoreagzfymn`)

**Справочные таблицы — сама матрица.** Страница при открытии читает их из базы. Если база недоступна, работает на встроенной копии.

| Таблица | Что в ней |
|---|---|
| `strat3_d3_processes` | 127 процессов: блок, направление, название, тип Global / Local / Mix, зоны Global и Local, согласование, KPI; `en` — английская версия |
| `strat3_d3_functions` | 28 карточек справочника функций: задачи, спорные зоны, конфликты, решения и вето из анкет; `en` — английская версия |
| `strat3_d3_process_functions` | Привязка процессов к функциям по умолчанию |

Править справочник можно прямо в Table Editor Supabase: изменения появятся на странице после обновления.

**Живое состояние сессии** — таблица `strat3_d3_docs` (одна строка на документ, обновляется в реальном времени у всех участников):

| `path` | Что это |
|---|---|
| `votes/p{№}_{роль}` | Позиция участника: ступень и ★ |
| `dec/p{№}` | Решение: ступень, кто решает, порог, срок HQ, метрика, статус (`decided` / `r11`), владелец и срок для реестра 1.1 |
| `links/p{№}` | Привязка функций, изменённая на сессии |
| `comments/{id}` | Комментарии |
| `extra/{id}` | Процессы, добавленные на сессии |
| `config/people` | Участники разметки (HQ — голос CEO, дивизионы) |
| `config/present` | Слайд и язык ведущего для трансляции залу |

Каждое изменение пишется в `strat3_d3_history` (с клиента недоступна) — из неё можно восстановить любое значение.

**Представления для анализа** (читаются как обычные таблицы):

- `strat3_d3_register` — итоговый реестр: процесс, позиции всех участников, решение, функции, число комментариев;
- `strat3_d3_votes`, `strat3_d3_decisions`, `strat3_d3_comments` — то же по отдельности.

Выгрузка в Excel — кнопка «Скачать Excel» над матрицей. Файл на языке, выбранном в интерфейсе, пять листов:

- **Реестр 1.0** — все процессы: зоны Global и Local, позиции каждого участника (цветом ступени), ★, решение, кто решает, порог, срок HQ, метрика, статус, реестр 1.1, функции;
- **Комментарии** — все комментарии с ролью, типом и временем;
- **Справочник функций** — 28 карточек и число привязанных процессов;
- **Лестница** — пять ступеней;
- **Сводка** — статусы по блокам.

Из базы то же можно выгрузить в CSV: Table Editor → `strat3_d3_register` → Export.

## Подготовка к сессии

Очистить тестовые отметки (справочник и список участников остаются):

```sql
delete from strat3_d3_docs where coll in ('votes','dec','links','comments','extra');
delete from strat3_d3_docs where path = 'config/present';
```

Вернуть значение из истории:

```sql
select id, op, at, data from strat3_d3_history where path = 'dec/p83' order by at desc;
insert into strat3_d3_docs(path, coll, data)
select path, split_part(path,'/',1), data from strat3_d3_history where id = <id>
on conflict (path) do update set data = excluded.data;
```
